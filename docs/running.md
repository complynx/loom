# Локальный запуск и клиентский flow

Целевая платформа — Linux amd64 с Docker. Сервис не запускается в Windows. Windows подходит для обычных Go-тестов; граница песочницы проверяется в Linux.

Этот Compose предназначен для разработки. Сопровождение установленного сервиса описано в [operations](operations.md). Конкретные серверные конфиги находятся вне репозитория.
